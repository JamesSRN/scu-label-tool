# README screenshots

Drop the screenshots for the main `README.md` here, using these **exact filenames** (the
README already references them). Use the **Developer Test** tab's random test patient so
there is **no real patient data (PHI)** in any image.

| Filename | What to capture | Framing tips |
|---|---|---|
| `medications-tab.png` | The **2. Medications** tab after Review, showing the color states | Include the toolbar (Add / Remove / Review) and a mix of **yellow** (missing), **blue** (reviewed OK), and **green** (checked) rows. |
| `review-dialog.png` | The **Medication Review** pop-up (click **Review**) | Capture just the dialog (or the dialog over the sheet) so the bold name + stacked errors are legible. |
| `print-gallery.png` | The **3. Print Labels** gallery | Show the orange banner with **Print Checked Labels / Refresh Previews** and at least one full label card. |
| `tebra-notes.png` | The **5. Tebra Notes** sheet | Show one patient's **green outer card** with the two teal inner boxes. |
| `log.png` | The **4. Log** | Show two or more encounters so the **divider line** and green banding are visible. |

How to capture on Windows: **Win + Shift + S** (Snip & Sketch), select the area, then
paste into Paint and **Save As** PNG into this folder with the name above - or use the
Snipping Tool's Save button directly.

Keep images reasonably sized (roughly 1000-1600 px wide is plenty for GitHub).
